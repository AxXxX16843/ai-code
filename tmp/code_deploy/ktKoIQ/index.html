我们相信，食物是情感的载体

始于2020年，悦食是一家融合东方美学与法式烹饪技艺的现代小馆。我们从本地农场直采时令食材，配合开放式厨房，让每一道菜都充满温度。

「悦」者，静心品味，与友共食。 我们提供自然酒与无酒精调饮，打造轻松静雅的用餐氛围。

—— 主厨 · 林泽
