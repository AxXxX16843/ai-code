番茄炒蛋

酸甜多汁，10分钟快手下饭菜。

📋 食材

  • 番茄 2个
  • 鸡蛋 3枚
  • 葱花 / 盐 / 糖

蒜蓉西兰花

脆嫩清爽，低卡高纤维。

📋 食材

  • 西兰花 1颗
  • 蒜末 3瓣
  • 生抽 / 蚝油

香煎鸡胸肉

外焦里嫩，低脂高蛋白。

📋 食材

  • 鸡胸 1块
  • 黑胡椒 / 盐
  • 橄榄油 1勺

凉拌黄瓜

爽口开胃，3分钟搞定。

📋 食材

  • 黄瓜 2根
  • 蒜泥 / 醋 / 香油
  • 小米辣 可选

👨‍🍳 烹饪小贴士

  • ✨ 番茄炒蛋加少许糖更提鲜。
  • 🥦 西兰花焯水后过凉水保持翠绿。
  • 🍗 鸡胸肉用刀背拍松，煎前腌10分钟更嫩。
